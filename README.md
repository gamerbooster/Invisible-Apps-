👻 Invisible Apps

Invisible Apps es un proyecto Android que permite administrar qué aplicaciones aparecen en un lanzador personalizado.

✨ Funciones

- Consultar las aplicaciones disponibles.
- Elegir cuáles mostrar u ocultar en Invisible Apps.
- Abrir aplicaciones desde el lanzador.
- Guardar las preferencias del usuario.

🛠️ Tecnologías

- Kotlin
- Android SDK
- Gradle
- Android Studio

📲 Instalación y compilación

1. Descarga o clona este repositorio.
2. Abre el proyecto en Android Studio.
3. Sincroniza Gradle.
4. Ejecuta la aplicación en un dispositivo Android.

⚠️ Limitaciones

Android no permite que una aplicación normal oculte otras aplicaciones de Ajustes ni modifique directamente sus iconos y nombres en todos los lanzadores.
